# TrimDesk: 2-minute demo video script

Record at 1366×768 in a clean Chrome window (no bookmarks bar, zoom 100%) on the deployed link.
Start each scene already signed in; switch roles between takes, not on camera.
Numbers on screen come from the seeded data, so read them off the screen rather than this script.

| Time | Screen | Voice-over |
|---|---|---|
| 0:00–0:12 | **HQ dashboard** (HQ login), 30-day range | "This is every McKingstown outlet on one screen, live. Today it's Excel sheets emailed in at night." |
| 0:12–0:20 | Hover the revenue chart, then the outlet ranking | "Revenue, bills and the best and weakest outlets, updated as each bill is saved." |
| 0:20–0:45 | **Billing** (cashier, T. Nagar). Show a stopwatch overlay. Type a new phone number, Enter, type a name, Enter, press 1, 2, F3, Ctrl+P | "At the counter, the cashier never touches the mouse. Phone number, services by number key, F3 for UPI, and the receipt prints. Under 20 seconds." |
| 0:45–1:05 | Esc, type 99105 51967, Enter. Point at the visit list | "A regular from another outlet walks in. His history follows him across the chain: where he went, what he had, who cut his hair." |
| 1:05–1:20 | Back on HQ: the **Today** card shows the new bills | "And HQ already sees those bills. No end-of-day reports." |
| 1:20–1:45 | **Royalty** page, last month. Point at one franchise's royalty due, then Export CSV | "Royalties calculate themselves: each franchise's taxable revenue times its rate, ready for the accountant as a spreadsheet." |
| 1:45–1:55 | Phone: dashboard on the bottom-tab layout | "Owners get the same view on their phone." |
| 1:55–2:00 | Login screen with the TrimDesk logo | "TrimDesk. Every counter, every outlet, one desk." |

## Before recording

- [ ] Demo data seeded to end on the recording day (`GROOMDESK_SEED_END_DATE`), so the Today card is busy
- [ ] One practice run of the 0:20 billing scene to land under 20 seconds
- [ ] Do not press Send on a WhatsApp message to a seeded customer: their numbers may belong to real people
- [ ] Hide desktop notifications
